# 🏦 Banco Pichincha - Login UI (Android)

Interfaz de inicio de sesión inspirada en la app móvil del Banco Pichincha, desarrollada como proyecto académico en Android Studio.

---

## 📱 Descripción

Este proyecto consiste en el diseño e implementación de una pantalla de login **responsive** para Android, replicando la interfaz del Banco Pichincha. La app muestra las opciones de autenticación disponibles y se adapta correctamente a distintos tamaños de pantalla.

---

## ✨ Características

- Pantalla de bienvenida con logo y versión de la app
- Ilustración principal adaptable al tamaño de pantalla
- Tres métodos de inicio de sesión:
  - 👤 Usuario y contraseña
  - 🫆 Huella / Face ID
  - 🔢 Pin de 6 dígitos
- Accesos rápidos: Ubícanos, Clave digital, Llámanos
- Diseño responsive que ocupa toda la pantalla
- Opción de ingresar con otro usuario
